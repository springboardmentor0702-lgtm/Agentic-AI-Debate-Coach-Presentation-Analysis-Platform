# Project implementation plan

## Phase 1: foundation and startup
- Confirm repository layout and baseline environment.
- Fix Python import/test bootstrap issues.
- Establish SQLAlchemy models and dependency wiring.
- Enable secure auth and protected routes.
- Ensure FastAPI startup works with SQLite for tests and PostgreSQL for production.

## Phase 2: user and debate flows
- Add authentication endpoints and JWT handling.
- Add profile and skill endpoints.
- Add debate creation, listing, update, delete, and message handling.
- Validate API flows through pytest.

## Phase 3: frontend shell and dashboard
- Add login/register/dashboard pages and authenticated state.
- Connect frontend to the real backend API.
- Verify build and lint behavior.

## Current status
- Phase 1 foundation is implemented and under active validation.
- Authentication and debate routes are in place.
- Remaining work is finishing the security bugfix and validating the actual app with tests and a frontend build.
